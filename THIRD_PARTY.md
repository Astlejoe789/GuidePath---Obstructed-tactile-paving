# Sources and dependencies

- Assignment: supplied RAP Constrained Object Detection & Reasoning API brief and recruitment email. They define requirements; no RAP endorsement is implied.
- WOTR author repository and published dataset links: https://github.com/kxzr/WOTR. Attribution: Xia et al., A dataset for the visually impaired walk on the road, Displays 79 (2023), 102486. Verify image/dataset terms separately from repository code licensing before redistribution. No dataset images are bundled.
- RT-DETR implementation and training interface: https://docs.ultralytics.com/models/rtdetr/ and https://docs.ultralytics.com/modes/train/ (checked 13 September 2026). See the upstream package license and applicable terms.
- RT-DETR paper: https://arxiv.org/abs/2304.08069.
- FastAPI: https://fastapi.tiangolo.com/; Pillow: https://pillow.readthedocs.io/; PyTorch: https://pytorch.org/.
- The custom web interface uses HTML, CSS and browser Canvas without external visual assets. 3D coordinates and demo detections are authored synthetic illustrations.

The PDF reports summarize project design and evidence status. The technical memo is the short screening document; the illustrated report is supplementary. Competitor code has not been copied into this package.
